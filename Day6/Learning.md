1. Numeric Functions

Numeric functions are used to perform mathematical operations on numeric values such as salary, bonus and age.
- ROUND() – Rounds a number to the specified decimal places.
- CEIL() – Returns the next highest integer.
- FLOOR() – Returns the next lowest integer.
- ABS() – Returns the absolute (positive) difference.
- MOD() – Returns the remainder after division.
- POWER() – Calculates the power of a number.
- SQRT() – Calculates the square root of a number.
- TRUNCATE() – Removes decimal digits without rounding.

2. String Functions

String functions are used to manipulate and retrieve information from text values.
- UPPER() – Converts text into uppercase.
- LOWER() – Converts text into lowercase.
- LENGTH() – Returns the length of a string in bytes.
- CONCAT() – Combines two or more strings.
- LEFT() – Extracts characters from the left side.
- RIGHT() – Extracts characters from the right side.
- REPLACE() – Replaces a specified string with another string.
- REVERSE() – Reverses a string.
- LOCATE() – Finds the position of a character or substring.
- SUBSTRING() – Extracts a part of a string.

3. SQL Joins

Joins are used to combine records from two or more tables based on a related column.
- INNER JOIN – Returns only matching records from both tables.
- LEFT JOIN – Returns all records from the left table and matching records from the right table. Unmatched values appear as NULL.
- RIGHT JOIN – Returns all records from the right table and matching records from the left table. Unmatched values appear as NULL.
- CROSS JOIN – Returns all possible combinations of records from both tables.
